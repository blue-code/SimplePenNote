# TestFlight 1.2.0 (13)

## 변경

- 마지막으로 고른 종이로 + 버튼 한 번에 새 노트 생성. 별도 종이 선택 유지
- 펜 색·굵기 기억, 접을 수 있는 도구 막대, 쓰기 크기와 필기 중심 보기
- 무료 PNG 미리보기와 여백 자동 제거, 필기를 가리지 않는 워터마크 여백
- 기존 Pro 상품에 투명 PNG 공유·복사 추가, 구매 화면에서 돌아올 때 내보내기 설정 복원
- 빠른 메모·가벼운 스케치에 맞춘 한국어·영어 스토어 문구 준비

## 검증

- Debug 앱 및 27개 XCTest/UI 테스트 빌드 통과
- 실기기용 Release 빌드 통과 (서명 없이 컴파일 확인)
- `scripts/validate-note-model.sh` 통과: 실제 저장 모델, 설정 복원, PNG 좌표·크기·알파값·인코딩, 종이 밖 필기, 자른 종이 선 정렬, 무료 워터마크 여백
- 생성된 PNG 이미지 시각 확인
- iOS 실행 테스트는 시뮬레이터의 `NSMachErrorDomain -308 (server died)`로 러너 실행 전에 실패. UI·Sandbox 구매·Apple Pencil·기기 간 iCloud 검증 완료로 간주하지 않음
