## 추가 업로드 없이 상태 확인

```sh
fastlane ios beta_status
```

`upload_state.state = PROCESSING`은 Apple의 처리 대기 상태입니다. `processing = VALID`와 내부 테스트 상태가 확인되기 전에는 배포 완료로 간주하지 않습니다.
