SimplePenNote는 미니멀한 손글씨 노트 앱입니다. 다음을 검토 시 참고 부탁드립니다.

1. 사용자 계정 / 로그인 없음. 모든 데이터는 사용자의 iCloud (CloudKit private DB)에만 저장됩니다.
2. 인앱 결제 (SimplePenNote Pro, 일회성, 비소모성): 무료 5페이지 한도 도달 시 또는 설정 시트에서 호출됩니다.
3. Face ID / Touch ID는 사용자가 설정 시트에서 활성화한 경우에만 사용되며, 인증 결과만 사용합니다.
4. 외부 서버 / 분석 SDK / 광고 없음.
